深圳楼市观察

数据来源与口径

成交套数和面积来自深圳市住建局公开的二手房成交统计，筛选用途为住宅。日表按日期和行政区汇总，字段包括日期、区、用途、套数、面积和序号。价格走势采用国家统计局发布的深圳二手住宅销售价格指数。

各区数据按可查范围展示，缺少记录时留空。价格指数反映价格变动幅度，单位为百分比。
