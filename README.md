# 深圳二手房成交跟踪

[打开看板](https://wa1king.github.io/shenzhen-resale-tracker/)

## 政府数据

- [深圳市住房和建设局 · 二手房成交信息（按日统计）](https://opendata.sz.gov.cn/data/dataSet/toDataDetails/29200_01903513)。按日期、行政区和房屋用途发布套数、面积。看板取住宅，支持按日、自然周、自然月查看趋势、区域份额、套均面积与历史记录。
- [深圳市住房和建设局 · 数据发布专栏](https://zjj.sz.gov.cn/xxgk/ztzl/pubdata/)。已收录的月度数字在明细中逐条链接到政府公开出处，缺期留空。
- [国家统计局 · 70 个大中城市商品住宅销售价格变动情况](https://www.stats.gov.cn/sj/zxfb/202610/t20261019_1965609.html)。取表 2、表 4（一）的深圳二手住宅指数，支持全市总体及三个面积段的环比和同比。逐月链接至发布页。指数基于统计调查，变动率为发布指数减 100。

按周或按月从日度数据汇总时，同一区域须有完整日期记录。分区占比以同期间的全市总量为分母，分区缺失会提示。成交总价段占比、逐套成交价、挂牌历史和议价率需要额外的政府数据，当前在看板中标明覆盖情况。

## 更新与发布

可从官方开放数据集下载 CSV 或 JSON，在网页的「更新数据」中导入。文件需包含日期、所属区、用途、成交套数和成交面积五个字段。浏览器校验字段与住宅记录，导入内容留在当前浏览器。官方完整下载需登录和实名认证。

维护者可运行 `python scripts/refresh-transactions.py` 更新内置日度数据。脚本使用 Python 3 和 curl，读取官方公开预览并保留此前收录的日期与区域。每次预览最多返回 50 条各用途记录，完整历史仍需从官方平台下载。

站点为静态网页。GitHub Pages 从 `main` 的 `/docs` 发布。可用浏览器直接打开 `docs/index.html` 预览。
